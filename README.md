# پرسشنامهٔ فارسی مدیریت تجربه — XM Iran

سایت ایستا و آمادهٔ بارگذاری در GitHub Pages، با بک‌اند Google Apps Script و ذخیره در Google Sheets.

**شروع از اینجا:** [راهنمای فارسی راه‌اندازی](README_FA.md)

## وضعیت تحویل

- فرم فارسی راست‌به‌چپ، دو لوگوی ارائه‌شده و رنگ‌های سازمانی.
- پاسخ‌های الزامی، ذخیرهٔ محلی پیش‌نویس، بازبینی و ویرایش پیش از ثبت.
- سه رتبهٔ متمایز در هر سؤال اهمیت و دقیقاً سه چالش.
- اعتبارسنجی سمت سرور، رسید و کد پیگیری، جلوگیری از ثبت دوبارهٔ همان شناسه.
- تاریخ شمسی و ساعت تهران در دو ستون جداگانه.
- ۹ آزمون بک‌اند و آزمون مرورگر در عرض‌های ۳۲۰، ۳۹۰ و ۱۲۸۰ پیکسل موفق بوده‌اند.

**پیش از انتشار:** نشانی Web app را در `config.js` وارد کنید، تنظیمات Google Apps Script را انجام دهید و یک پاسخ آزمایشی واقعی ثبت کنید. اتصال زنده به حساب گوگل در این محیط آزمایش نشده است. فایل‌های دارای مجوز فونت Dana ارائه نشده‌اند؛ تا افزودن آن‌ها فونت جایگزین نمایش داده می‌شود.

این پروژه ابزار ساخت یا کتابخانهٔ اجرایی خارجی لازم ندارد. `index.html` باید در ریشهٔ مسیر انتشار قرار بگیرد. برای جزئیات، محدودیت‌ها، عیب‌یابی و آزمون‌ها به راهنمای فارسی مراجعه کنید.
